# Internet Speed Test

Простой скрипт на Python для замера скорости интернета через последовательные HTTP-запросы к указанному URL.

## Что делает

1. Принимает URL «тяжёлого» ресурса (например, большой картинки или файла).
2. Последовательно выполняет 10 HTTP-запросов (число настраивается).
3. Замеряет время каждого запроса и объём скачанных данных.
4. Считает среднее время запроса и среднюю скорость в **МБ/с**.
5. Печатает красивый отчёт в консоль.

## Требования

- Python 3.9+
- pip

## Установка

```bash
git clone https://github.com/<ваш-логин>/internet-speed-test.git
cd internet-speed-test

python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate

pip install -r requirements.txt
```

## Использование

Базовый запуск (URL по умолчанию — файл на 100 МБ с speed.hetzner.de):

```bash
python speed_test.py
```

Свой URL:

```bash
python speed_test.py https://example.com/big-image.jpg
```

Другое количество запросов:

```bash
python speed_test.py https://example.com/big-image.jpg -n 5
```

Таймаут запроса (сек):

```bash
python speed_test.py https://example.com/big-image.jpg -t 30
```

## Как это работает

- Используется `requests.Session()` — TCP-соединение переиспользуется, поэтому мы меряем именно пропускную способность канала, а не оверхед на установку соединения.
- Время замеряется через `time.perf_counter()` — монотонные часы высокого разрешения.
- Скорость = суммарный объём / суммарное время (а не среднее от средних — так математически корректнее).
- Ответ читается целиком (`stream=False`), поэтому замеряется полное скачивание файла.
